# Manual Reviews

## What this does

Explains requirements that cannot be decided safely from collected CLI output.

## When you use it

Use this when Results shows **Manual Review Required**.

A manual item is not an application failure. It means deterministic automation cannot defend a status with available evidence. Review the DISA procedure, gather the indicated evidence, then record Open, Not a Finding, Not Applicable, or Not Reviewed with finding details and comments. Manual decision editing remains an area for continued GUI expansion; exported CKL/CKLB retains compatible status terminology.
