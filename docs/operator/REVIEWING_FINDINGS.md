# Reviewing Findings

## What this does

Explains the result dashboard and finding evidence traceability.

## When you use it

Use it after an audit completes or when reopening History.

Filter by CAT level or status, or search hostname, IP, Vuln ID, Rule ID, STIG ID, or title. Selecting a result shows the requirement, plain-language evaluation reason, failed objects, evidence commands and files, Site Profile inputs, and parser warnings. **View Evidence** opens raw output and its stored SHA-256. **DISA Check Text** and **DISA Fix Text** show guidance from the installed release; fix text is informational and is never executed.
