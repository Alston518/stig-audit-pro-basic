# Device Management

## What this does

Explains how to build reusable, validated switch target lists.

## When you use it

Use this before an audit or when the environment changes.

Add individual IP addresses, paste several addresses, or import `.csv`/`.txt` files from **Audit Run**. Imports are limited to 5 MB and 10,000 CSV rows. A preview reports valid devices, duplicates, and invalid entries before anything is added. Save recurring selections as a device group. Credentials are never part of a group or preset.

Use check boxes for bulk audit selection. Removing a target from the current workbench does not delete historical audit results.
