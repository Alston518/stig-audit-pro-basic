# Administrator Guide (v0.2)

This compatibility entry point now links to the current
[operator administrator guide](operator/ADMINISTRATOR_GUIDE.md),
[audit history guide](operator/AUDIT_HISTORY_GUIDE.md), and
[STIG update workflow](operator/STIG_UPDATE_GUIDE.md).

Live audits use bounded concurrent workers and exact approved commands. Audit
runs, evidence, profile/check snapshots, and result context are retained
locally until explicitly deleted. The product remains read-only; finding review
and any configuration change are separate authorized activities.
