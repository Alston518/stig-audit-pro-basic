# Basic IOS / IOS XE check setup worksheet

These files accompany the **3 October 2026 combined reporting tester package**.
The worksheet was expanded on 5 October 2026. It covers all 121 packaged IOS
and IOS XE L2/NDM checks and tells an operator exactly where to enter each
site-specific value in the selected profile YAML file. It also identifies
checks that require no profile input and checks that need manual review.

- [Word worksheet (editable)](05_Check_By_Check_Setup_Worksheet.docx)
- [PDF worksheet](05_Check_By_Check_Setup_Worksheet.pdf)
- [HTML worksheet (searchable in a browser)](05_Check_By_Check_Setup_Worksheet.html)

The profile paths in the worksheet refer to the **extracted tester package**
under `Application/data/profiles`. Choose the IOS or IOS XE profile on the
Audit tab, then edit that selected profile before scanning. Keep any completed
worksheet and site profile values in your own private site workspace.
