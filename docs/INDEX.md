# STIG Audit Pro Documentation

STIG Audit Pro 0.2 is a read-only Cisco IOS-XE assessment desktop application. It collects explicitly approved evidence, evaluates YAML-defined checks, preserves historical audit context, and exports operator-facing reports and DISA checklist formats.
